# 🛒 Clothing Shop – Full-Stack Shopping Cart Application

**Live Demo:** [shopping-cart-e0e7d.web.app](https://shopping-cart-e0e7d.web.app)

A fully functional e-commerce shopping cart built with **React** and **Redux**, integrated with **Firebase** for backend services. This project includes all essential features required for a seamless online shopping experience.

🚀 Features
🔄 State Management using Redux and Reducers

🔐 User Authentication & Authorization with Firebase

💳 Secure Payment Integration

📬 Shipping Address management

📦 Order Tracking

🧾 Dynamic Receipts generation and order summaries

⚡ Real-time Firestore Database

📱 Responsive UI for mobile and desktop

🔧 Tech Stack
Frontend: React, Redux

Backend/Database: Firebase (Authentication, Firestore)

Payment: Stripe or mock gateway

State Handling: Redux Toolkit / Custom Reducers

Styling: CSS Modules or Tailwind (if used)
